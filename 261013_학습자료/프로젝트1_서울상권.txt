장황한 텍스트 설명이나 단순한 데이터 표(Table) 위주의 출력을 지양하고, 
[https://two61012-hw.onrender.com] 서비스처럼 UI가 극도로 깔끔하고, 시각적이며, 사용자의 카테고리/상권 선택에 따라 즉각적으로 화면과 차트가 전환되는 인터랙티브 웹 대시보드 코드를 작성해 줘.

---

[1. 시각적 UI/UX 제약 조건]
1. 레이아웃: 싱글 페이지(Single Page) 대시보드 형태로 구성하고, 화면 상단 또는 사이드바(Sidebar)에 셀렉트 박스(Selectbox)나 라디오 버튼을 배치해 유저가 '상권 선택'을 바꾸면 하단의 지도와 차트, 카드 뉴스가 실시간으로 재렌더링되게 해줘.
2. 카드 UI 활용: 상권의 핵심 정보와 장/단점은 텍스트 줄글이 아니라, Streamlit의 st.metric이나 custom HTML/CSS 카드를 활용해 계량화된 수치와 아이콘(공간 활용)으로 직관적으로 배치해 줘.
3. 지도 중심 시각화: 대시보드의 메인은 'Folium 인터랙티브 지도'여야 해. 서울시 주요 상권 좌표를 기준으로 K-Means 군집화 결과(성장, 활성화, 정체, 쇠퇴)에 따라 마커 색상(Red, Green, Blue, Purple 등)을 다르게 표시해 줘.

[2. 백엔드 로직 및 데이터 구조 (내장 데이터 생성)]
- 서울의 대표 상권 10~15개(예: 성수, 홍대, 강남역, 명동, 문래동, 신당동 등)를 정의하고 데이터를 생성해 줘.
- 데이터 컬럼: 상권명, 위도(Latitude), 경도(Longitude), 최근 1년 매출 추이, 점포수 변화율, 공실률.
- K-Means 로직: sklearn.cluster.KMeans를 사용해 위 데이터를 기반으로 4개의 Cluster를 실제로 연산하고, 각 Cluster에 [성장 / 활성화 / 정체 / 쇠퇴] 레이블을 매핑해 줘.

[3. 대시보드 화면 기능 구성 (MVP 필수 스코프)]
1. Top Section (글로벌 현황): 
   - 서울 전체 지도 위에 4개 군집으로 분류된 상권 마커를 표시. 마커를 클릭하면 상권 이름과 진단 단계가 팝업으로 노출됨.
2. Left/Right Split Section (상권 상세 진단):
   - 유저가 사이드바에서 '특정 상권(예: 성수동)'을 선택하면 즉시 전환되는 영역.
   - [좌측 컬럼]: 해당 상권이 속한 '군집'의 공통 DNA 요약 카드 (평균 임대료, 주요 유입 연령대, Top 3 업종 비율).
   - [우측 컬럼]: 해당 상권의 '장점 / 단점' 분석 카드 UI (예: 장점 - "20대 유동인구 폭발적 증가", 단점 - "최근 2분기 연속 임대료 상승 압박").
3. Bottom Section (데이터 트렌드 시각화):
   - 선택된 상권의 최근 매출 추이를 보여주는 깔끔한 선형 차트(Line Chart) 혹은 바 차트(Bar Chart) 배치 (st.plotly_chart 등 인터랙티브 차트 권장).
