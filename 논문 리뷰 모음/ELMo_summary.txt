================================================================================
ELMo: Deep Contextualized Word Representations (Peters et al., 2018)
================================================================================

1. 개념 설명 (Concept Explanation)
--------------------------------------------------------------------------------
• Contextual Word Representations (문맥 반영 단어 표현):
  - 기존 워드 임베딩(Word2Vec, GloVe 등)은 'apple'이나 'play'처럼 여러 의미를 가진 단어에도 고정된 단 하나의 숫자 벡터만 할당하는 한계가 있었습니다.
  - ELMo는 문장 전체의 앞뒤 흐름(맥락)을 동적으로 읽어내어, 동일한 단어라도 문맥에 따라 전혀 다른 가변 벡터 표현을 생성합니다.

• Sentence-Level Embedding (문장 수준 임베딩):
  - 단어를 개별적으로 다루지 않고 문장 전체의 구조와 관계 속에서 각 단어의 의미적·문법적 위치를 통합 파악합니다.
  - 단어 수준을 넘어 문장 전체의 고차원 맥락 정보가 단어 벡터 속에 깊이 녹아들게 됩니다.

• Bidirectional Language Model (biLM, 양방향 언어 모델):
  - 문장을 왼쪽에서 오른쪽으로 읽으며 다음 단어를 예측하는 Forward LM과, 오른쪽에서 왼쪽으로 읽으며 이전 단어를 예측하는 Backward LM을 통합한 언어 모델입니다.


2. 모델 프로세스 (Model Process)
--------------------------------------------------------------------------------
[1단계] 사전 학습 (Pre-training biLM)
  - 대규모 텍스트 코퍼스(약 3,000만 문장)를 활용해 2개 레이어의 양방향 LSTM(biLSTM) 언어 모델을 학습시킵니다.
  - 문자 단위 CNN(Character Convolution) 표현을 최하단에 적용하여, 단어장에 없는 모르는 단어(Out-of-Vocabulary)도 문자를 구성하는 n-gram 특징으로 다룰 수 있습니다.

[2단계] 내부 레이어 정보의 선형 결합 (Linear Combination)
  - 입력 단어 $t_k$에 대해 ELMo는 최하단 문자 레이어, 1번째 biLSTM 레이어, 2번째 biLSTM 레이어 등 총 3가지 형태의 내부 표현 벡터를 추출합니다.
  - 연구 결과, 하위 레이어(1st layer)는 품사(POS)나 구문 분석 등 '문법적 정보(Syntax)'를 잘 잡고, 상위 레이어(2nd layer)는 다의어 구별 등 '깊은 의미적 정보(Semantics)'를 잘 잡는다는 것을 발견했습니다.
  - 최상단 레이어만 쓰지 않고, 풀고자 하는 특정 자연어 처리 과제(Task)에 맞게 각 레이어 표현에 가중치($s_j$)와 전체 스케일($\gamma$)을 곱해 가중합(Linear Combination)을 수행합니다.

[3단계] 기존 모델에 결합 (Task Integration)
  - 사전 학습된 biLM의 무게중심(가중치)은 고정(Freeze)한 채, 기존 과제별 신경망 모델의 입력층 또는 출력층에 ELMo 벡터를 이어 붙여(Concatenate) 함께 학습시킵니다.


3. 논문 핵심 인사이트 (Key Insights)
--------------------------------------------------------------------------------
• "신경망의 속살(내부 모든 레이어)을 전부 활용하라":
  - 기존에는 딥러닝 모델의 맨 마지막 층 출력만 사용했으나, ELMo는 모델 내부 모든 층이 서로 다른 차원의 언어 정보(문법 vs 의미)를 담고 있음을 밝혀내고 이를 가중합함으로써 대폭적인 성능 향상을 이끌어냈습니다.

• 6대 NLP 과제 전반에서의 압도적 SOTA 달성 및 데이터 효율성:
  - 질의응답(SQuAD), 자연어 추론(SNLI), 의미역 할당(SRL), 개체명 인식(NER) 등 6개 주요 과제에서 기존 최선 모델 대비 상대 오차를 6~20%나 줄였습니다.
  - 적은 양의 학습 데이터(예: 전체의 1%)만으로도 기존 모델이 10%의 데이터를 썼을 때와 대등한 성능을 내는 뛰어난 데이터 효율성(Sample Efficiency)을 보였습니다.
