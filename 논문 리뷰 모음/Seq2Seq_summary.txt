================================================================================
Seq2Seq: Sequence to Sequence Learning with Neural Networks (Sutskever et al., 2014)
================================================================================

1. 개념 설명 (Concept Explanation)
--------------------------------------------------------------------------------
• Sequence Transformation (시퀀스 변환):
  - 기존 심층 신경망(DNN)은 입력과 출력의 데이터 크기가 고정되어 있을 때만 사용 가능했습니다.
  - Seq2Seq는 입출력의 길이가 일정하지 않고 단어 간 1:1 대응이 되지 않는 가변 길이 시퀀스(예: 문장)를 다른 가변 길이 시퀀스로 변환하는 범용 엔드투엔드(End-to-End) 학습 방법론입니다.

• Encoder-Decoder 구조 (인코더-디코더):
  - 문장을 읽고 이해하는 '인코더(Encoder)'와 이해한 내용을 바탕으로 새로운 언어 문장을 작성하는 '디코더(Decoder)' 역할을 분리된 두 개의 신경망으로 구성한 구조입니다.

• Machine Translation (기계 번역):
  - 통계적 기계번역(SMT)에 의존하던 시기, 오직 신경망(LSTM)만으로 문장 전체의 맥락을 파악하여 자연스러운 번역문을 생성해내는 인공신경망 기계번역(NMT) 시대를 열었습니다.


2. 모델 프로세스 (Model Process)
--------------------------------------------------------------------------------
[1단계] Encoder (인코더) 문장 압축 프로세스
  - 4개의 층으로 쌓아 올린 깊은 LSTM(Multilayered LSTM)을 사용합니다.
  - 입력 문장(예: 영어 "A B C <EOS>")의 단어를 한 시점(timestep)씩 순차적으로 읽어들입니다.
  - 입력 문장의 마지막 단어 및 문장 끝 토큰(`<EOS>`)까지 읽은 후, 인코더 LSTM의 마지막 숨은 상태(Hidden State)에 전체 문장의 의미를 담아 하나의 '고정 차원 벡터(Context Vector / Thought Vector, 8,000차원)'로 압축합니다.

[2단계] Decoder (디코더) 번역 생성 프로세스
  - 인코더가 만들어낸 고정 차원 벡터를 디코더 LSTM의 초기 상태(Initial State)로 주입받습니다.
  - 디코더는 이 문맥 벡터와 이전에 자신이 생성한 단어들을 조건으로 삼아, 목표 언어(예: 불어 "W X Y Z <EOS>")의 단어를 한 시점씩 빔 검색(Beam Search)을 통해 가장 확률이 높은 단어 순으로 순차적 생성합니다.

[3단계] 입력 문장 뒤집기 (Reversing Source Sentences)
  - 입력 문장의 단어 순서를 반대로 뒤집어서(예: "A B C" 대신 "C B A") 인코더에 입력합니다.
  - 원문의 첫 단어("A")와 번역문의 첫 단어("W") 사이의 물리적 거리(Minimal Time Lag)가 매우 가까워지면서, 경사하강법(SGD) 학습 시 역전파 신호가 훨씬 잘 전달되어 최적화가 대폭 쉬워집니다.


3. 논문 핵심 인사이트 (Key Insights)
--------------------------------------------------------------------------------
• "단순히 데이터 순서만 뒤집어도 신경망의 장기 기억력이 비약적으로 상승한다":
  - 기존 신경망은 긴 문장을 만나면 앞부분 내용을 잊어버리는 고질병이 있었으나, 입력 문장을 역순으로 넣는 비결(Reversing Trick) 하나만으로 긴 문장에서도 번역 성능 저하가 거의 발생하지 않음을 증명했습니다.

• 문장 의미 공간의 형성 (Word Order & Voice Invariance):
  - 인코더가 생성한 고정 차원 벡터들을 PCA로 2차원 시각화해 본 결과, 모델이 단어 순서에 민감하게 반응하면서도, 능동태와 수동태처럼 표현 방식은 달라도 의미가 동일한 문장들은 서로 매우 가깝게 클러스터링함을 확인했습니다.

• 오직 신경망만으로 기존 통계적 기계번역(SMT) 능가:
  - WMT'14 영-불어 번역 과제에서 오직 신경망만 사용한 단일 모델/앙상블로 BLEU 34.81을 달성하여 기존 프레이즈 기반 통계 번역(33.30)을 뛰어넘었으며, SMT 결과를 재정렬(Rescoring)하여 36.5 SOTA 급 성능을 기록했습니다.
