================================================================================
[쉬운 인공지능 논문 요약집] Transformer: "Attention Is All You Need"
================================================================================

이 자료는 2017년 구글이 발표한 딥러닝 혁신의 전환점, "Transformer(트랜스포머)" 논문을 비전공자도 쉽게 이해할 수 있도록 핵심 개념과 구조를 정리한 요약본입니다.

--------------------------------------------------------------------------------
1. 핵심 키워드 4가지 쉬운 개념 설명
--------------------------------------------------------------------------------

[키워드 1] Attention Is All You Need (어텐션만 있으면 충분하다)
• 기존 방식의 문제점: 
  과거의 AI(RNN 모델)는 글을 읽을 때 사람처럼 단어를 "첫 번째 -> 두 번째 -> 세 번째" 순서대로 하나씩 읽었습니다. 이 방식은 문장이 길어지면 앞쪽 내용을 잊어버리고, 계산을 한 번에 할 수 없어 시간이 매우 오래 걸렸습니다.
• 트랜스포머의 혁신:
  "굳이 순서대로 하나씩 읽을 필요 없이, 문장 전체에서 '어디에 집중(Attention)할지'만 계산하면 된다!"라는 파격적인 아이디어를 제안했습니다. 복잡한 복습/예습 구조(RNN, CNN)를 다 버리고 오직 Attention 기법 하나만으로 최고 성능을 달성했습니다.

[키워드 2] Self-Attention (자기 자신에게 집중하기)
• 비유로 이해하기:
  "그 동물은 길을 건너지 않았다. 왜냐하면 그것이 너무 피곤했기 때문이다." 라는 문장에서 '그것(it)'이 가리키는 것은 '동물'일까요, '길'일까요?
  사람은 문맥을 보고 '동물'임을 바로 알 수 있습니다. Self-Attention은 문장 안의 모든 단어가 서로 어떤 관계를 맺고 있는지 '스스로' 계산하여, 문맥적 의미를 파악하는 기술입니다.
• Q, K, V 핵심 원리:
  - Query (질문): "내가 찾아야 하는 단어의 특징은 뭐야?"
  - Key (주소/열쇠): "내 단어가 가진 특징은 이거야!"
  - Value (내용): "나의 실제 단어 의미 값이야!"
  Query와 Key를 비교해 관련성(점수)을 구한 뒤, 그 점수만큼 Value를 섞어서 문맥이 반영된 단어 뜻을 완성합니다.

[키워드 3] Positional Encoding (위치 정보 주입하기)
• 왜 필요한가?:
  트랜스포머는 문장의 모든 단어를 한꺼번에 동시에 읽습니다. 그렇다 보니 "사과가 배를 먹는다"와 "배가 사과를 먹는다"처럼 단어 순서가 바뀔 때의 의미 차이를 구분하지 못하는 문제가 생깁니다.
• 해결 방법:
  단어 자체의 뜻(임베딩)에 "너는 1번째 단어야", "너는 2번째 단어야"라는 위치 신호(주파수가 다른 사인/코사인 삼각함수 값)를 살짝 더해줍니다. 이를 통해 순서 개념까지 완벽하게 학습합니다.

[키워드 4] Parallel Processing (병렬 처리)
• 비유로 이해하기:
  - 기존 RNN (순차 처리): 100페이지 책을 한 사람이 첫 장부터 끝까지 한 줄씩 순서대로 읽기 (이전 줄을 읽어야 다음 줄 읽음)
  - 트랜스포머 (병렬 처리): 100명이 책 100페이지를 한꺼번에 나누어 동시에 읽기
• 핵심 효과:
  GPU와 같은 그래픽 카드의 수천 개 계산 코드를 동시에 활용할 수 있어, AI 학습 시간을 며칠/몇 주에서 단 몇 시간 수준으로 혁신적으로 단축시켰습니다.

--------------------------------------------------------------------------------
2. 트랜스포머 모델의 전체 프로세스 및 구조
--------------------------------------------------------------------------------

트랜스포머는 크게 '인코더(Encoder)'와 '디코더(Decoder)' 두 파트로 나뉩니다.
예: "I am a student" (영어) -> "나는 학생이다" (한국어 번역)

[1단계: 입력 단어 변환 (Input Embedding + Positional Encoding)]
• 문장의 단어들을 숫자의 배열(벡터)로 바꾸고, 거기에 위치 정보(Positional Encoding)를 더해 모델에 넣어줍니다.

[2단계: 인코더 (Encoder) - 문장 완전 이해하기]
• 총 6개의 동일한 층(Layer)이 쌓여 있습니다.
• 각 층에서는 Multi-Head Self-Attention을 통해 단어들 간의 관계와 문맥을 깊이 있게 파악합니다.
• 이해한 내용을 종합하여 '문장의 의미 지도'를 만들어 디코더로 보냅니다.

[3단계: 디코더 (Decoder) - 단어 순차 생성하기]
• 디코더도 6개의 층으로 구성됩니다.
• Masked Self-Attention: 번역문을 만들 때 아직 나오지 않은 미래의 단어를 미리 스포일러해서 읽지 못하도록 가립니다.
• Encoder-Decoder Attention: 인코더가 전달해 준 원문 의미 지도를 참고하여, 다음에 들어올 가장 적절한 단어를 하나씩 예측해 나갑니다.

--------------------------------------------------------------------------------
3. 각 단계별 핵심 용어 정리
--------------------------------------------------------------------------------

1. Scaled Dot-Product Attention:
   Query와 Key를 곱하여 유사도 점수를 계산할 때, 값이 너무 커지지 않도록 √d_k 값으로 나누어(Scale) 안정적으로 확률을 계산하는 방식입니다.

2. Multi-Head Attention:
   단어를 한 가지 관점으로만 보지 않고, 8개(h=8)의 서로 다른 시각(헤드)으로 동시에 문장을 분석합니다. (예: 문법적 관계 보는 헤드, 대명사 가리키는 헤드 등)

3. Residual Connection (잔차 연결) & Layer Normalization:
   정보가 여러 층을 거치면서 손실되거나 폭주하지 않도록, 입력 값을 그대로 전달해 더해주고(Add) 신호를 일정하게 정돈(Norm)해 줍니다.

4. Feed-Forward Neural Network (FFN):
   Attention을 거친 정보를 각 단어 위치별로 개별 처리하여 더욱 풍부하고 복잡한 특징을 추출해 내는 인공신경망 단계입니다.

--------------------------------------------------------------------------------
[요약 결론]
Transformer는 "순서대로 읽지 말고 한 번에 다 보고(Parallel), 서로의 연관성만 집중해서 다면적으로 파악하자(Self-Attention + Multi-Head)"는 원리로 AI 언어 모델의 표준(GPT, BERT 등)이 된 혁신적인 구조입니다.
