================================================================================
Seq2Seq_attention: Neural Machine Translation by Jointly Learning to Align and Translate (Bahdanau et al., 2014)
================================================================================

1. 개념 설명 (Concept Explanation)
--------------------------------------------------------------------------------
• Attention Mechanism (어텐션 메커니즘):
  - 기존 Seq2Seq 모델이 전체 문장을 오직 하나의 '고정 길이 벡터'에 강제로 압축하면서 긴 문장(30~50단어 이상)에서 정보 손실(Bottleneck Problem)이 발생하는 문제를 해결하기 위해 도입되었습니다.
  - 디코더가 번역 단어를 하나씩 생성할 때마다 입력 문장 전체를 다시 지켜보며, 어떤 단어에 주의(Attention)를 얼마나 기울여야 하는지 동적으로 계산합니다.

• Context Vector (동적 컨텍스트 벡터):
  - 이전처럼 고정된 단 하나의 벡터가 아니라, 디코딩하는 매 시점마다 입력 문장의 각 위치별 중요도(가중치)를 반영하여 다르게 계산되는 '시점별 맞춤형 문맥 벡터'입니다.

• Alignment and Translation (정렬과 번역의 동시 학습):
  - 과거 통계 번역에서 별도로 수행하던 단어 위치 맞춤(Alignment) 과정을 신경망 내부에 Soft Alignment 형태로 포함시켜, 정렬 모델과 번역 모델이 하나의 신경망 안에서 동시에 학습되도록 설계했습니다.

• Variable-Length Input Handling (가변 길이 입력 처리):
  - 문장 길이가 50단어 이상으로 길어져도 번역 품질이 급격히 떨어지지 않고 높은 BLEU 점수를 유지하는 뛰어난 내구성을 증명했습니다.


2. 모델 프로세스 (Model Process)
--------------------------------------------------------------------------------
[1단계] Bidirectional RNN Encoder (양방향 인코더)
  - 입력 문장을 정방향(Forward)과 역방향(Backward) RNN으로 동시에 읽습니다.
  - 단어 위치의 정방향 숨은 상태와 역방향 숨은 상태를 이어 붙여(Concatenate), 단어 주변의 앞뒤 맥락 정보가 모두 집약된 '주석 벡터(Annotation Vector)' 시퀀스를 만듭니다.

[2단계] Soft Alignment 및 동적 Context Vector 계산
  - 디코더가 i번째 단어를 생성하기 직전, 이전 상태와 인코더의 모든 주석 벡터를 피드포워드 신경망(Alignment Model)에 전달합니다.
  - Softmax 함수를 적용하여 각 입력 단어 위치별 상대적 중요도(Attention Weight)를 산출합니다.
  - 이 어텐션 가중치와 주석 벡터들의 가중합을 구해 현재 디코딩 시점에 필요한 동적 컨텍스트 벡터를 생성합니다.

[3단계] Decoder 번역 단어 생성
  - 디코더는 이전 생성 단어, 디코더 숨은 상태, 그리고 맞춤형 컨텍스트 벡터를 종합하여 다음 출력 단어의 확률을 계산하고 생성합니다.


3. 논문 핵심 인사이트 (Key Insights)
--------------------------------------------------------------------------------
• "압축하지 말고, 필요할 때 찾아봐라 (Search and Attend)":
  - 정보를 하나의 고정된 벡터에 억지로 우겨넣는 방식에서 벗어나, 번역할 단어를 만들 때마다 원문에서 필요한 위치를 찾아보는 소프트 서치(Soft-search) 방식을 구현해 NMT의 가장 큰 한계였던 정보 병목 현상을 완벽히 해소했습니다.

• 직관적이고 설명 가능한 어텐션 가중치 시각화:
  - 어텐션 가중치 행렬을 2차원 흑백 히트맵으로 시각화한 결과, 영어와 프랑스어 간의 어순 역전(예: "European Economic Area" -> "zone économique européenne")이나 단어 수 불일치를 모델이 스스로 자연스럽게 정렬하고 있음을 명확히 증명했습니다.

• 현대 AI (Transformer 및 LLM)의 기틀 마련:
  - 인간이 글을 읽을 때 관련 부분에 시선을 주듯 AI가 맥락을 선택적으로 참조하게 만드는 'Attention'의 개념을 도입함으로써, 향후 Transformer 및 ChatGPT 등 대형 언어 모델(LLM) 발전의 가장 중요한 기술적 초석을 놓았습니다.
