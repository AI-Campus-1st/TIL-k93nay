4. 코드라인
 - 1줄에 1문장이 원칙
 - 기본적으로 ;을 사용하지 않음 (줄바꿈을 사용할때 쓰나, 자주쓰지 않음)
 - 여러 줄 작성할 때에는 역슬래시를 이용하면 한줄의 문자열로 출력 가능
 - [], {}, ()는 역슬래시 없어도 여러줄에 나눠 작성 가능(한줄의 문자열로 출력) - 이떄에는 인덴트(띄어쓰기 공백) 맞춰 작성, [],{},()는 인덴트나 최초 시작위치에 맞추면 됨
 - end 옵션의 기본은 '역슬래시n' 형태 -> end='(원하는 값)'으로 문자열 마지막 마무리 가능
 
5. 표현식 
 - 하나의 값으로 환원할 수 있는 문장
 - 식별자, 값, 연산자로 구성. 하나의 값으로 평가될 수 있어야함 ("hello" 등등)
 - a=34와 같이 할당문(명령)의 경우, 값을 반환하지 않는 문장이므로 표현식이 될 수 없음
 - 위의 할당문을 기초로 쓰여진 수식 (a*2 + 10) 등은 표현식
 - 표현식은 문장 중 일부 범위

9. 숫자 타입
파이썬에서는 가장 큰 숫자 활용을 위해 sys 모듈을 불러움(import sys) : 파이썬의 정수는 오버플로우 없이, 임의 정밀도 산술 진행(메모리양 유동적)
* int(integer) : 정수

binary_number = 0b10 : 2진수 
octal_number = 0o10 : 8진수
decimal_number = 10 : 10진수
hexadecimal_number = 0x10 : 16진수

print(binary_number) : 2
print(octal_number) : 8
print(decimal_number) : 10
print(hexadecimal_number) : 16

* float() : 실수

(1) e-2(10의 -2제곱)과 같은 지수 표현도 가능
b = 314e-2
print(b) : 3.14
type(b) : float

(2) 산수를 할 때, 값이 반드시 일치하지는 않음
(ex. (3.5 - 3.12) == 0.38 : False. 3.5-3.12값이 0.379999999999로 나오기 때문)

(3) 이때 round(표현식 값, 소수점자릿수)로 맞출 수 있음
(ex. round(3.5-3.12, 3) == 0.38 : True) : 이때 round는 소수점 위치 값이 0~4일 경우 내림을, 5는 짝수에서는 내리고, 홀수에서는 올림, 6이상은 반올림하여 계산

(4) abs() : 절대값 계산
abs() <= 1e-10(10의 -10승) 이 성립하면, 값이 같다고 판단
a = 3.5-3.12
b = 0.38
abs(a-b)
abs(a-b) <= 1e-10 
-> 'True' 산출

(5) 4번과 같은 뜻으로 아래 표현식도 있음
import sys
abs(a - b) <= sys.float_info.epsilon
혹은
import math
math.isclose(a, b)

(6) 그 외 complex(복소수)가 있음 (ex. 1+2j) -> 출력 시 '(1+2j)'로 출력됨

(ex. bool(['']) -> list안에 '' 라는 값이 있으므로 True)

11. 비교연산자
<. <=, >, >=, ==, !=, is, is not 
문자열 비교시에는 대소문자 구분도 진행
(ex. 'HI' != 'hi' : True)

12. 논리연산자
a and b : True and True, True and False, False and True, False and False -> (True, False, False, False)
즉, and는 앞,뒤가 모두 True로 성립되어야 True이기 때문에 -> 앞이 True면 뒤쪽(b) 값 확인(출력), 앞이 False면 바로 False이므로 앞쪽(a)값 확인(출력) 
a or b
즉, or는 앞,뒤 중 하나만 True로 성립되어도 True이기 때문에 -> 앞이 True면 바로 앞쪽(a) 값 확인(출력), 앞이 False면 뒤쪽(b) 값 확인(출력)
not a
반대값을 출력하는 것 (True -> False, False -> True)
(ex.
print(3 and 5)
print(3 and 0)
print(0 and 3)
print(0 and 0)

5 (true -> 뒤쪽값 출력)
0 (true -> 뒤쪽값 출력)
0 (false -> 앞쪽값 출력)
0 (false -> 앞쪽값 출력)
)
