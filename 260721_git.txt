github - 커뮤니티(게시판)
git - 글 작성 프로그램

최초 작성자(author) 설정
git config --global user.name "닉네임"
git config --global user.email "이메일 주소"

최초 1회 실행
git clone 저장소의 주소(github의 주소) : github의 폴더 및 자료를 다운받는 주소 
-> 이후는 git pull 사용

내가 만든 걸 github에 올리는 법
git이라는 프로그램을 사용
1. git bash 열기
2. git init : "여기를 git 저장소로 관리하겠다"는 뜻 (최초 1회만)
3. git remote add origin 저장소 주소(github의 주소) : 저장소 연결 (최초 1회만)

github 저장소에 올리기
1. git add 파일들 (모든 파일은 '.')  ->  git stasus : 업로드 상태 확인
2. git commit -m "기록 메세지"  -> git log : 메세지 등록상태 확인
3. git push origin master(main)

또 올리는(수정하는) 방법 : 'github 저장소에 올리기' 같은 방식으로 반복
