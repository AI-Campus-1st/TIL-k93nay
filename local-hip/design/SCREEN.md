# SCREEN.md (종합 화면 명세서 - v2.1 전체 완전본)

## '로컬 힙' 지수 서비스 종합 화면 명세서 (v2.1 전체 완전본)

본 명세서는 `BASE.md`에서 정의한 Pinterest 스타일의 웜 크림 크롬(Warm-Cream Chrome) 디자인 자산과 3-Radius 시스템을 기반으로, 웹 서비스 v1(MVP)의 전체 화면 구조(SCR-01, SCR-02, SCR-03), 각 화면별 UI 구성 요소, 동적 인터랙션 및 예외 처리 규정을 처음부터 끝까지 완전하게 규정합니다.

---

### 1. 시스템 통합 지도 엔진 명세

- 본 서비스의 모든 화면(SCR-01, SCR-02, SCR-03)은 **네이버지도 API v3 (`Naver Maps JS API v3`)**을 전면 적용합니다.
- 기존 Mapbox GL JS 스펙은 국내 상세 보행자 도로망/상권 라벨 데이터 부족 이슈로 전면 폐기되었으며, 네이버지도 SDK로 대체 구현합니다.

---

### 2. 통합 화면 구조 및 레이아웃 레이어 매트릭스

#### 기본 레이아웃 레이어 구성 (모바일 뷰 최적화 기준)
- **Layer 0 (Base)**: 네이버지도 전면 공간 지도 캔버스 (`naver.maps.Map`, `rounded.none`)
- **Layer 1 (Sticky-Top)**: 서비스 상단 내비게이션 바
   * **구조**: `height: 64px`, `backgroundColor: #ffffff`, `borderBottom: 1px solid #e5e5e0`, `padding: 0 24px`
   * **좌측**: Local Hip 네온 로고 ("Local Hip" 텍스트 + `#ff1493` 포인트 닷)
   * **우측**: **'사람 아이콘 / 마이페이지' 프로필 버튼 (`user-profile-avatar`, 40px 원형 `#f7f7f3` 패널 + SVG 사람 아이콘)** & 알림 종 아이콘 (`24px`)
- **Layer 2 (Floating)**: 지도 위 한 줄 알약 조건 필터바 (`floating-filter-bar`, Height: 56px, `flex-nowrap`, `overflow-x: auto`)
- **Layer 3 (Overlay/Sliding-Up)**: 3초 요약 팝업 카드 (`sliding-up-summary-card`, 32px 상단 코너) 및 공유 토스트 알림 (`toast-notification`)

| 화면 ID | 화면명 | 주요 UI 컴포넌트 | 지도 엔진 API 연동 및 개편 스펙 |
| --- | --- | --- | --- |

### 3. 화면별 상세 명세 (UI 구성요소, 와이어프레임, 동적 인터랙션 및 예외처리)

---

#### SCR-01. 지도 홈 & 탐색 화면

- **사용자 맥락**: 주말 약속 장소를 고민하며 서비스를 켜고, 확장된 한 줄 알약 필터바(프랜차이즈 제외, 업종 칩, 보행/상점 인라인 슬라이더)를 조작하여 실시간 마커를 확인하는 화면.
- **개편사항**: 필터바 길이를 960px~1080px로 확장하여 내부 슬라이더 2개가 흰 배경 안쪽에 100% 여유롭게 안착되며, 상단바 우측에 40px 원형 사람 프로필 버튼이 적용됨.

##### [화면 레이아웃 구조도 - Wireframe]
```
+-------------------------------------------------------------------+
| [Local Hip Logo]                          [로그인] [시작] [마이페이지]| -> primary-nav (64px)
+-------------------------------------------------------------------+
|                                                                   |
|  +-------------------------------------------------------------+  |
|  | (O) 프랜차이즈 제외 | [소품 v] [카페 v] | 🏃 보행 [=o=] | 🏪 상점 [=o=] | -> floating-filter-bar (한 줄 배치)
|  +-------------------------------------------------------------+  |
|                                                                   |
|                 ( Blur Donut Marker )                             |
|                   total_walk_score: 92                            | -> naver.maps.CustomOverlay
|                  (네온 핫핑크 번짐 효과)                            |
|                                                                   |
|                                                                   |
+-------------------------------------------------------------------+
```

##### A. UI 구성 요소 설명
1. **상단 내비게이션 바 (`primary-nav`)**: Pure White (`#ffffff`) 배경, 좌측 네온 로고, 우측 로그인/시작하기 버튼. 1px `#e5e5e0` 하단 경계선.
2. **한 줄 알약 조건 필터바 (`floating-filter-bar`)**:
   - `display: flex`, `flex-direction: row`, `flex-wrap: nowrap`, `overflow-x: auto` (한 줄 유지 및 가로 스크롤).
   - **대형 프랜차이즈 제외 토글**: 기본값 ON (`flex-shrink: 0`).
   - **선호 업종 멀티 칩**: '감성 카페', '이색 소품샵', '독립 서점', '빈티지 숍' 등 둥근 알약 칩.
   - **인라인 미니 슬라이더 2종**: '보행 쾌적도 🏃' (기본 50%), '독립상점 비율 🏪' (기본 50%)를 필터바 내부에 콤팩트하게 한 줄 정렬.
3. **네이버지도 블러 도넛 마커 (`map-hotspot-marker`)**:
   - `naver.maps.CustomOverlay` 클래스로 구현.
   - `total_walk_score` 점수(0~100pt)에 비례하여 마커 크기(24px ~ 48px)와 핫핑크/네온 오렌지 블러 반경(10px ~ 20px)이 실시간 연산되어 은은하게 빛남.

##### B. 동적 인터랙션 및 예외 처리 (Interaction & Exception Rules)
1. **필터 실시간 리렌더링**:
   - 유저가 가중치 슬라이더를 드래그하거나 업종 칩을 선택하는 즉시 `POST /api/v1/walk-score/calculate` API가 호출됨.
   - **1초 이내**에 지도 위의 네이버지도 CustomOverlay 블러 도넛 마커 크기와 색상 농도가 부드러운 애니메이션과 함께 동적으로 갱신됨.
2. **데이터 Null 값 방어**:
   - 특정 신생 골목 데이터가 누락되어 백엔드에서 Null 또는 0점 값이 반환되더라도 화면 레이아웃이 깨지지 않음.
   - 디폴트 평균 수치를 대입하고 웜 크림 면 (`#f7f7f3`)으로 자리를 유지함.
3. **한 줄 필터바 오버플로우 방지**:
   - 모바일 등 좁은 화면에서도 `flex-wrap: nowrap` 및 `overflow-x: auto` 적용으로 요소가 아래로 처지거나 잘리지 않고 가로 스크롤을 통해 한 줄 인터페이스를 100% 보장함.

#### SCR-02. 골목 상세 및 요약 카드 화면

- **사용자 맥락**: 가장 붉은 마커(문래창작촌 뒷골목) 터치 시 3초 만에 골목 특징, TOP 3 독립 상점, 주변 유사 골목 비교분석 5축 레이더 차트(`RadarChart`)를 확인하는 화면.
- **개편사항**: 주변 유사 골목(성수/을지로)의 색상 조합을 검정/노랑에서 Soft Muted Gray(`#d1d1ca`) 점선 및 15% 투명 회색 면으로 연하게 조정하여, 선택한 핫핑크(#ff1493) 골목이 강력한 시각적 주도권을 갖도록 함.

##### [화면 레이아웃 구조도 - Wireframe]
```
+-------------------------------------------------------------------+
|                                                                   |
|             /=============================\                       |
|            /  # # # # # # # # # # # # #   \                       | -> naver.maps.Polygon
|           (  # 문래창작촌 뒷골목 하이라이트 # )                    |    (네온 핫핑크 #ff1493 외곽선)
|            \  # # # # # # # # # # # # #   /                       |
|             =============================/                       |
|                                                                   |
+===================================================================+
|  문래창작촌 뒷골목 [차없는 안심 골목]                 [ 92.5 ]    | -> heading-lg / 점수 배지
|  #차없는도로 #소품샵천국 #도보천국                                 | -> caption-md
|                                                                   |
|  [대표 독립 상점 TOP 3]                                           |
|  +-------------------+ +-------------------+ +-------------------+ |
|  |     [이미지]      | |     [이미지]      | |     [이미지]      | | -> 16px 둥근 미니 카드
|  |  상점A (와인바)   | |  상점B (소품샵)   | |  상점C (스튜디오) | |    (풀블리드 이미지)
|  +-------------------+ +-------------------+ +-------------------+ |
|                                                                   |
|  [주변 유사 골목(성수·을지로) 비교분석 레이더 차트]                   |
|  (5축 이중 다각형 RadarChart: 인도분리도, 다양성, 감성지수 등)      |
|                                                                   |
|  [ 이 골목 탐방 코스 추천받기 ]                                      | -> button-primary (#ff1493)
+===================================================================+ -> sliding-up-summary-card (32px)
```

##### A. UI 구성 요소 설명
1. **골목 구역 하이라이트 (`naver.maps.Polygon`)**:
   - 선택된 골목 구역 바닥면 경계를 네온 핫핑크 (`rgba(255, 20, 147, 0.9)`) 4px 두꺼운 실선과 15% 투명도 면 채우기 (`fillColor: rgba(255,20,147,0.15)`)로 하이라이트 강조.
2. **슬라이딩 업 요약 카드 (`sliding-up-summary-card`)**:
   - 상단 32px (`rounded.lg`) 둥근 모서리가 적용된 하단 슬라이딩 시트 구조.
   - **골목 메타 정보**: 자간이 -0.5px 압축된 22px 타이포그래피 (`heading-lg`) 및 감성 해시태그 (`caption-md`).
   - **종합 보행 점수 배지**: 우측 상단 28px (`heading-xl`) 세미볼드 핫핑크 배지.
   - **독립 상점 TOP 3 그리드**: 가로 3열 레이아웃, 16px (`rounded.md`) 미니 카드. 내부 패딩 없는 **풀블리드(Full-bleed)** 풀 사이즈 렌더링.
   - **주변 유사 골목 비교분석 차트 (`RadarChart`)**: 5개 평가 축(인도 분리도, 프랜차이즈 역비율, 독립상점 다양성, 감성 지수, 안전 보행도)을 가진 이중 다각형 레이더 차트.
   - **메인 CTA 버튼**: "이 골목 탐방 코스 추천받기" (`button-primary`, `#ff1493`, Height 44px).

##### B. 동적 인터랙션 및 예외 처리 (Interaction & Exception Rules)
1. **슬라이딩 업 애니메이션**:
   - 마커 터치 시 Spatial ID 기반 조회가 실행되며, 하단 시트가 **0.3초 내에 부드럽게 슬라이딩 업**되며 노출됨.
2. **카메라 확대 애니메이션 및 화면 전환 시퀀스**:
   - "이 골목 탐방 코스 추천받기" 클릭 시 백엔드 `POST /api/v1/courses/generate` 호출.
   - 네이버지도 카메라 애니메이션 실행: `map.morph(zoneCenterBounds, 17, { duration: 800 })` (800ms 동안 선택 골목으로 부드럽게 줌인).
   - 하단 카드가 슬라이드 다운되면서 `SCR-03` 코스 추천 화면으로 자연스럽게 라우팅됨.
3. **Fallback 카테고리 매핑**:
   - 공공 데이터 표준 분류에 잡히지 않는 신종 힙스터 트렌드 업종(`popup_space` 등)은 일반 독립 상점 아이콘 및 명칭으로 우회하여 안전하게 미니 카드를 생성함.

#### SCR-03. 코스 생성 및 공유 완료 화면

- **사용자 맥락**: 최적 도보 동선(1순위 실선, 대안 점선)을 네이버지도 위에 드로잉하고, 카카오톡 공유 버튼을 눌러 친구에게 링크를 전송하는 화면.
- **특징**: 표준 상단바(로고 + 사람 아이콘)를 보유하고 있으며, 공유 링크 재진입 시 가중치 슬라이더, 선택 골목 ID, 코스 Polyline 세션 파라미터를 100% 복원함.

|                                    (2.포스트포에틱스)              |
|                                       - - -                       | -> course-alternative-line

|  - 1. 신도림 보행교 진입로 (출발지)                                 |

##### A. UI 구성 요소 설명
1. **네이버지도 추천 코스 오버레이 (`naver.maps.Polyline`)**:
   - **1순위 / 선택 경로 (`course-primary-line`)**: `#ff1493` (네온 핫핑크), **5px 두께 실선(solid)**, `strokeOpacity: 0.95`.
   - **대안 / 기타 경로 (`course-alternative-line`)**: `#a1a19a` (Ash Gray), **3px 두께 점선(dashed, `6, 6`)**, `strokeOpacity: 0.65`.
   - **보행자 네트워크 매핑**: 단순 직결 선을 금지하고 네이버지도 보행자 길찾기 API 연동 실제 보행 도로망 노드 좌표 배열(`LineString`)을 매핑.
2. **상점 순번 배지 마커 (`naver.maps.Marker`)**: 1, 2, 3, 4 커스텀 HTML 순번 마커 배지 표출.
3. **공유 토스트 알림 (`toast-notification`)**: Ink Black (`#111111`) 배경에 Pure White 텍스트, `#9999px` 알약 형태 하단 플로팅 알림 ("카카오톡 공유 링크가 복사되었습니다!").

##### B. 동적 인터랙션 및 예외 처리 (Interaction & Exception Rules)
1. **1클릭 코스 드로잉**:
   - 코스 추천 클릭 즉시 지도 중심점이 자동 맞춤(`fitBounds`)되며, 보행자 네트워크 경로 라인과 순번 마커가 매핑되어 실선/점선으로 그려짐. (QA 검증: 차량 전용 대로변 포함 금지).
2. **공유 링크 세션 파라미터 보존 및 복원**:
   - 카카오톡 공유 버튼 클릭 시 URL 파라미터(`?zone_id=GEO_SEOUL_0032&walk_weight=70&store_weight=30&course_id=C_9281`)가 포함된 링크가 복사됨.
   - 외부 사용자가 해당 링크로 재진입했을 때, 유저가 설정했던 가중치, 선택 골목, 추천 경로 Polyline 좌표가 **동일하게 100% 복원**되어 렌더링됨.

### 4. MoSCoW 기준 화면 구현 개발 우선순위 가이드

1. **Must Have (v1 필수)**: SCR-01 전체 (네이버지도 타일 + 확장 필터바 + CustomOverlay 마커), SCR-02 기본 정보 및 TOP 3 풀블리드 미니 카드, 통일 상단바(`primary-nav`).
2. **Should Have (권장)**: SCR-03 1순위 실선 / 대안 점선 Polyline 드로잉 및 카카오톡 파라미터 세션 공유 연동.
3. **Could Have (선택)**: SCR-02 내부 5축 레이더 차트(`RadarChart`) 연한 회색조 시각화 고도화.
